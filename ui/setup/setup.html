Leftover account nodes

These folder-pane nodes were created by this add-on but no configured account claims them — typically from a setup that failed part way, or from removing and reinstalling the add-on, which wipes the extension's own storage while the node survives. Thunderbird offers no Delete button for this kind of account, so handle them here.
Restore re-adopts a node together with its original DeviceId, so the server keeps seeing the same device — no new partnership, no fresh quarantine. Deleting a node also deletes the mail stored in it.

    Reuse an existing ID to re-attach to a device partnership the server already knows — after reinstalling the add-on, or when moving to another profile. Avoids consuming another slot of the mailbox device quota and starting a fresh quarantine.
